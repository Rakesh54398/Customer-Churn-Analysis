# Customer-churn-project

## 📉 Customer Churn Analysis

**Key Finding:** Customer Churn Rate is **42.10%** - Out of every 100 customers, 42 are leaving.

**Tools Used:** SQL, Power BI, Excel / Python for Data Cleaning
**Files / 
Customer Churn Project /
-Raw Data 
(subscriptions.csv & usage.csv)  
-After Cleaning Using Python & Excel
(subscriptions_clean.csv & Usage cleaned.csv)
-Analysis Using SQL 
(Customer_churn_analysis.sql & exploratory analysis.sql)
-Dashboard Using PowerBI 
(customer_churn_report.pbix)


**What I Did:**
1. Cleaned Raw Data (Removed Duplicates, Handled Missing Values)
2. Analyzed Churn using SQL (Churn by Engagement, Plan, Age Group)
3. Built Interactive Power BI Dashboard to visualize Churn



**Business Impact:** --Identified that low-engagement customers are churning more. Recommended to focus on retention to save revenue.
                     --Monthly Subscripted customers Are Churning More Than Annual Subscripted Customers. Give free Access For one Month.
